At a Glance: What is the Circulation Desk? Lending & Security

This is where books are issued, returned, and renewed. Notice the RFID connection: when you issue a book, its RFID tag security bit is disarmed (0) so it won't alarm the security gate. When returned, it is re-armed (1) to protect against theft.

Imports legacy spreadsheets (~20,000 records) safely into the library database. It uses an isolated staging table so live data is never corrupted, rejects malformed/duplicate rows, reconciles counts, and provides an instant undo button (atomic rollback).
